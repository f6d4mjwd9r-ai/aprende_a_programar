Fundamentos de Java y Python

Java y Python permiten crear instrucciones, trabajar con datos y resolver problemas. Comparten conceptos como variables, condiciones y ciclos, pero difieren en la sintaxis y en los paradigmas que enfatizan.

Cada tarjeta explica un concepto y permite consultar un resultado de ejemplo. Los resultados son simulaciones locales: no ejecutan código Java o Python libre.

Antes de programar, entiende qué pide el problema, separa los datos y decide qué pasos podrían resolverlo.

Prueba tu razonamiento con ejemplos y comprueba si el resultado tiene sentido.

Fundamentos · Resolver problemas

                
La lógica antes de programar

                
Antes de abrir el editor, puedes resolver el problema en papel. Leer con atención, hacerte preguntas y probar tus ideas te ayuda a encontrar los pasos correctos; después, esos pasos se convierten en código.

                
Ejemplo: calcular el promedio de dos notas

                
Imagina que recibes las notas 8 y 10. En vez de empezar a programar, piensa como si estuvieras resolviendo el ejercicio en tu cuaderno:

                

                    
    
                        
  1. 
                            Entiendo qué me piden
                            ¿Qué resultado necesito? El promedio de las dos notas.
                        
    2. 
                        
  2. 
                            Separo los datos
                            ¿Qué información tengo? La primera nota es 8 y la segunda es 10.
                        
    3. 
                        
  3. 
                            Elijo los pasos y explico por qué
                            Sumo las notas y divido entre 2, porque son dos notas: 8 + 10 = 18; 18 ÷ 2 = 9.
                        
    4. 
                        
  4. 
                            Cuestiono y compruebo
                            Si ambas notas fueran 6, el promedio sería 6. Si fueran 0 y 10, sería 5. Los resultados tienen sentido.
                        
    5. 
                    

                    
Mi solución, escrita en palabras: recibir dos notas, sumarlas, dividir la suma entre dos y mostrar el resultado.

                

                
Este razonamiento también aclara una suposición: las dos notas tienen el mismo valor. Si una nota pesara más que la otra, habría que pensar otro cálculo.

                
De la idea al algoritmo

                
Cuando puedes explicar los pasos y comprobarlos con ejemplos, ya tienes un algoritmo: una serie ordenada de instrucciones para resolver el problema.

                
    
                    
  • Entrada: las dos notas que recibimos.
    • 
                    
  • Proceso: sumarlas y dividir la suma entre dos.
    • 
                    
  • Salida: el promedio calculado.
    • 
                

                
                
La misma lógica en Java y Python

                
La lógica no depende del lenguaje. En ambos ejemplos se calcula el promedio; lo que cambia es la forma de escribir las instrucciones.

                

                    

                        
Java

                        
public class Main {
    public static void main(String[] args) {
        double nota1 = 8.0;
        double nota2 = 10.0;
        double promedio = (nota1 + nota2) / 2;
        System.out.println(promedio);
    }
}

                    

                    

                        
Python

                        
nota1 = 8.0
nota2 = 10.0
promedio = (nota1 + nota2) / 2
print(promedio)

                    

                

                

                    
¿Qué hace el programa paso a paso?

                    
    
                        
  1. nota1 y nota2 guardan las calificaciones 8 y 10. double en Java y los números con decimal en Python permiten trabajar con resultados fraccionarios.
    2. 
                        
  2. (nota1 + nota2) suma las dos notas: 8 + 10 = 18.
    3. 
                        
  3. Al dividir la suma entre 2, el programa calcula el promedio: 18 / 2 = 9.
    4. 
                        
  4. El resultado se guarda en promedio. System.out.println en Java y print en Python lo muestran en pantalla.
    5. 
                    

                    
Lo que verás en la consola:9.0

                

                
Comprueba la solución

                
Prueba el algoritmo con distintos valores y verifica el resultado a mano. También considera casos especiales: ¿qué ocurre si falta una nota o si el problema permite más de dos?
