Fundamentos de Java y Python

Java y Python permiten crear instrucciones, trabajar con datos y resolver problemas. Comparten conceptos como variables, condiciones y ciclos, pero difieren en la sintaxis y en los paradigmas que enfatizan.

Algoritmos

Son conjuntos ordenados de pasos para resolver un problema o completar una tarea.

Ejemplo: leer dos números, sumarlos y mostrar el resultado.

Datos y variables

Los tipos comunes incluyen enteros, decimales, texto y valores booleanos. Java declara el tipo de cada variable; Python lo determina a partir del valor asignado.

Java: int edad = 20; · Python: edad = 20. En Python puedes consultar un tipo con type(edad).

Condiciones y ciclos

Las condiciones if y else eligen qué instrucciones ejecutar. Los ciclos for y while repiten acciones; sirven, por ejemplo, para procesar todos los elementos de una lista.

Java usa llaves y suele escribir else if; Python usa dos puntos, sangría y elif.

Ver explicación completa

Funciones

Una función agrupa instrucciones bajo un nombre. Puede recibir parámetros y devolver un resultado. En Java, las funciones asociadas a una clase se llaman métodos.

Python las define con def; Java especifica el tipo que devuelve y el de cada parámetro.

Ver explicación completa

Cadenas y caracteres

Aprende a guardar texto y acceder a caracteres o fragmentos usando sus posiciones.

Java usa charAt; Python permite indexar y obtener segmentos con cortes.

Ver explicación completa

Listas y arreglos

Permiten guardar varios valores relacionados y procesarlos con ciclos. Python ofrece listas; Java usa arreglos y colecciones como ArrayList.

Una lista de calificaciones facilita calcular un promedio sin crear una variable por cada nota.

Ver explicación completa

Clases y objetos

Una clase describe datos y acciones que tendrán sus objetos. Java organiza sus programas alrededor de clases; Python también permite definirlas.

Una clase Libro podría guardar el título y el autor de cada libro.
