Algoritmos

Un algoritmo es una serie de instrucciones claras y ordenadas que permite resolver un problema. Una receta, las indicaciones para llegar a un lugar y un programa son ejemplos de algoritmos.

Cómo diseñar uno

Antes de escribir código, identifica qué información tienes, qué resultado necesitas y qué pasos conectan ambos. Por ejemplo, para calcular el promedio de dos notas, se reciben las notas, se suman y el total se divide entre dos.

  • Entrada: los datos que el problema proporciona, como dos notas.
  • Proceso: las operaciones que transforman esos datos.
  • Salida: el resultado que se comunica, como el promedio.

El mismo algoritmo en Java y Python

La lógica no depende del lenguaje. En ambos ejemplos se calcula el promedio; lo que cambia es la forma de escribir las instrucciones.

Java

public class Main {
    public static void main(String[] args) {
        double nota1 = 8.0;
        double nota2 = 10.0;
        double promedio = (nota1 + nota2) / 2;
        System.out.println(promedio);
    }
}

Python

nota1 = 8.0
nota2 = 10.0
promedio = (nota1 + nota2) / 2
print(promedio)

Comprueba la solución

Prueba el algoritmo con distintos valores y verifica el resultado a mano. También considera casos especiales: ¿qué ocurre si falta una nota o si el problema permite más de dos?
