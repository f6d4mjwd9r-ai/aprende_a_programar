Errores comunes en Java y Python

Un error puede impedir que el programa arranque o hacer que produzca un resultado incorrecto. Lee el mensaje, identifica la línea señalada y prueba una corrección.

SyntaxError en Python
if numero = 5:
    print("cinco")
SyntaxError: invalid syntax

Se usó = para comparar. Usa ==: if numero == 5:.

IndentationError en Python
if numero > 0:
print("positivo")
IndentationError: expected an indented block

El cuerpo de if debe ir indentado: agrega cuatro espacios antes de print.

cannot find symbol en Java
System.out.println(nombre);
error: cannot find symbol

El compilador no conoce nombre. Declara la variable antes de usarla, por ejemplo String nombre = "Ana";.

Falta ; en Java (';' expected)
int edad = 20
error: ';' expected

Falta el punto y coma al final de la instrucción: int edad = 20;.

NullPointerException en Java
String nombre = null;
System.out.println(nombre.length());
Exception in thread "main" java.lang.NullPointerException

Se intentó usar un objeto que no tiene valor. Inicializa nombre o comprueba que no sea null antes de llamar a sus métodos.

Asignar = en lugar de comparar con ==

En Python, if x = 5 da SyntaxError; en Java, con un int normalmente da error de compilación. Lee el mensaje y revisa el operador.

Para comparar, escribe if (x == 5) en Java o if x == 5: en Python.

El ciclo no termina o el resultado es inesperado
Comprueba que la condición pueda dejar de cumplirse y revisa los valores intermedios. Usa puntos de interrupción o imprime los valores para localizar el paso que falla.
