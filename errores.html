Errores comunes en Java y Python

Un error puede impedir que el programa arranque o hacer que produzca un resultado incorrecto. Lee el mensaje, identifica la línea señalada y prueba una corrección.

Falta un punto y coma o una llave
Java requiere punto y coma al final de muchas instrucciones y llaves para marcar bloques. Comprueba que estén completos y equilibrados.
La sangría es incorrecta
Python usa la sangría para definir bloques. Mantén la misma cantidad de espacios en instrucciones del mismo nivel.
Una variable tiene un valor inesperado
Comprueba dónde se asigna, qué tipo de dato contiene y si su valor cambia durante el programa.
Una condición nunca se cumple
Revisa los operadores de comparación: == compara valores, mientras que = asigna uno. Prueba casos que cubran ambas ramas.
Un ciclo no termina
Asegúrate de que la condición pueda dejar de cumplirse y de que el valor de control avance en cada repetición.
El resultado no es el esperado
Divide el problema en partes pequeñas y revisa los valores intermedios. Java ofrece depuración en el IDE; Python permite usar puntos de interrupción o print().
