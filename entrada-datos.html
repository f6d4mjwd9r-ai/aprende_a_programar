Fundamentos · Datos

Entrada de datos

Un programa puede pedir información a la persona que lo usa. Leer una entrada permite resolver el problema con datos distintos cada vez, en lugar de dejar un valor fijo en el código.

Python: input()

input() muestra un mensaje y espera a que escribas algo. El texto leído se convierte a número con int(); para decimales, usa float().

Python

edad = int(input("Escribe tu edad: "))
print("Tu edad es", edad)

Ejemplo

Entrada:
Escribe tu edad: 18

Salida:
Tu edad es 18

Java: Scanner

Java usa la clase Scanner para leer desde la consola. nextInt() lee un entero y nextDouble() lee un decimal.

La clase Main y el método main son la plantilla inicial del programa Java. Por ahora, puedes concentrarte en las instrucciones dentro de main.

Java

import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Escribe tu edad: ");
        int edad = sc.nextInt();
        System.out.println("Tu edad es " + edad);
        sc.close();
    }
}

Ejemplo

Entrada:
Escribe tu edad: 18

Salida:
Tu edad es 18

Recuerda

  1. La entrada es lo que la persona escribe cuando el programa la solicita.
  2. En Python, input() entrega texto; conviértelo con int() o float() si vas a hacer cálculos.
  3. En Java, Scanner ofrece métodos distintos según el tipo, como nextInt() y nextDouble().
