Fundamentos · Guardar información

Datos y variables

Los datos son la información que usa un programa. Una variable es un nombre asociado a un valor, para poder guardarlo, consultarlo y utilizarlo durante la ejecución.

Tipos de datos comunes

  • Enteros: números sin parte decimal, como 12.
  • Decimales: números con fracción, como 3.5.
  • Texto: caracteres entre comillas, como "Hola".
  • Booleanos: valores de verdad, true o false en Java y True o False en Python.

Declarar y cambiar variables

En Java se indica el tipo al declarar una variable y ese tipo no cambia. Python determina el tipo a partir del valor asignado. En ambos lenguajes se puede actualizar el valor de una variable compatible.

Java

int edad = 20;
double altura = 1.68;
String nombre = "Ana";
boolean estudia = true;

edad = edad + 1;
System.out.println(edad);

Python

edad = 20
altura = 1.68
nombre = "Ana"
estudia = True

edad = edad + 1
print(edad)

Elige buenos nombres

Usa nombres que expliquen para qué sirve cada dato, como totalCompra o promedio. Evita espacios y nombres que no describan el contenido. Python suele usar snake_case; Java suele usar camelCase para variables.
