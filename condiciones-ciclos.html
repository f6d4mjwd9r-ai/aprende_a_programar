Fundamentos · Tomar decisiones y repetir

Condiciones y ciclos

Las condiciones permiten elegir qué instrucciones ejecutar según una situación. Los ciclos repiten instrucciones cuando una tarea se debe realizar varias veces.

Elegir con una condición

Una expresión como nota >= 6 se evalúa como verdadera o falsa. Con if se ejecuta una acción si es verdadera; else ofrece una alternativa. Para varias opciones, Java utiliza else if y Python utiliza elif.

Repetir con ciclos

Usa un ciclo for cuando puedes recorrer una secuencia o conoces cuántas repeticiones necesitas. Usa while cuando la repetición depende de una condición que puede cambiar.

Java

int nota = 8;
if (nota >= 6) {
    System.out.println("Aprobado");
} else {
    System.out.println("A seguir practicando");
}

for (int i = 1; i <= 3; i++) {
    System.out.println(i);
}

Python

nota = 8
if nota >= 6:
    print("Aprobado")
else:
    print("A seguir practicando")

for i in range(1, 4):
    print(i)

¿Qué hace el programa paso a paso?

  1. La variable nota guarda el número 8.
  2. if (nota >= 6) pregunta si la nota es mayor o igual a 6. Como 8 >= 6 es verdadero, se muestra «Aprobado».
  3. else contiene la alternativa que se mostraría si la condición fuera falsa. Con la nota 8, esa parte se salta.
  4. El ciclo for repite una instrucción tres veces. La variable i toma los valores 1, 2 y 3; en cada vuelta se muestra su valor.
  5. En Python, range(1, 4) produce 1, 2 y 3: el límite final, 4, no se incluye.

Evita ciclos infinitos

En un ciclo while, comprueba que algo dentro del ciclo modifique la condición para que, tarde o temprano, deje de cumplirse. Si nunca cambia, el programa puede repetir el bloque indefinidamente.
