Primeros pasos

Prepara tu equipo para programar

Puedes instalar las herramientas en tu computadora o comenzar con un compilador en línea. Para empezar, instala un lenguaje y elige un editor; no es necesario instalar todo a la vez.

1. Instalar Python

  1. Descarga Python desde python.org/downloads.
  2. En Windows, durante la instalación marca Add Python to PATH si aparece esa opción.
  3. Abre una terminal y comprueba la instalación con py --version. En otros sistemas también puedes usar python3 --version.
  4. Guarda un archivo como programa.py y ejecútalo con py programa.py en Windows o python3 programa.py en macOS y Linux.

2. Instalar Java (JDK)

  1. Instala un JDK, que incluye el compilador y las herramientas necesarias. Puedes descargar Eclipse Temurin desde adoptium.net; elige una versión LTS y el instalador apropiado para tu sistema.
  2. Abre una terminal y verifica con java -version y javac -version.
  3. Guarda el ejemplo en un archivo llamado Main.java, porque la clase pública se llama Main.
  4. Compila y ejecuta desde esa carpeta: javac Main.java y luego java Main.

3. Elegir un editor

Puedes comenzar con un editor de texto. Visual Studio Code es una opción gratuita; para Java instala también la extensión Extension Pack for Java y para Python la extensión Python. Alternativamente, puedes usar un entorno integrado como IntelliJ IDEA Community para Java.

4. Probar en línea sin instalar

Un compilador en línea permite elegir Java o Python, pegar el código y pulsar Run. Si el programa pide datos, escríbelos en el panel llamado Input, stdin o similar antes de ejecutarlo. Por ejemplo, puedes probar Python o Java en OneCompiler.

Usa compiladores en línea con ejercicios de práctica; no pegues contraseñas, datos privados ni código confidencial.
