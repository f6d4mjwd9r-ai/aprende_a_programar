Fundamentos · Filas y columnas

Matrices

Una matriz organiza valores en filas y columnas, como una tabla. Cada elemento se localiza con dos índices: el primero indica la fila y el segundo la columna. Como en los arreglos y las listas, los índices comienzan en cero.

Declarar y consultar elementos

En Java, una matriz de enteros se declara con int[][]. En Python, puede representarse como una lista cuyos elementos también son listas. En ambos casos, matriz[1][2] consulta el elemento de la segunda fila y la tercera columna.

Java

int[][] matriz = {
    {1, 2, 3},
    {4, 5, 6}
};

int elemento = matriz[1][2];
System.out.println(elemento); // 6

Python

matriz = [
    [1, 2, 3],
    [4, 5, 6]
]

elemento = matriz[1][2]
print(elemento)  # 6

¿Cómo se localiza un valor?

  1. La matriz tiene dos filas: [1, 2, 3] y [4, 5, 6]. Se puede imaginar como una tabla de dos filas por tres columnas.
  2. El primer índice indica la fila y el segundo indica la columna. Ambos comienzan en cero.
  3. matriz[1] selecciona la segunda fila, [4, 5, 6]. Después, [2] selecciona el tercer elemento de esa fila: 6.
  4. Por eso matriz[1][2] guarda el valor 6 en elemento, y println o print lo muestra.

Resultado de consultar la posición [1][2]:6

Recorrer filas y columnas

Para visitar todos los valores, se usan dos ciclos: uno para las filas y otro para las columnas. En Python, cada fila se puede recorrer directamente. En Java, los índices permiten acceder a cada elemento.

Java

for (int fila = 0; fila < matriz.length; fila++) {
    for (int columna = 0;
         columna < matriz[fila].length;
         columna++) {
        System.out.println(matriz[fila][columna]);
    }
}

Python

for fila in matriz:
    for elemento in fila:
        print(elemento)

¿Qué hacen los dos ciclos?

  1. El ciclo exterior visita cada fila de la matriz.
  2. Para cada fila, el ciclo interior visita cada columna y obtiene el valor de esa posición.
  3. Cada valor se muestra antes de pasar al siguiente. Así se recorren primero 1, 2, 3 y después 4, 5, 6.
  4. matriz.length cuenta filas; matriz[fila].length cuenta las columnas de esa fila. En Python, for fila in matriz toma una fila cada vez.

Salida del recorrido:1
2
3
4
5
6

Revisa los límites

Una matriz de dos filas y tres columnas tiene índices de fila 0 y 1, e índices de columna 0, 1 y 2. Consultar una posición fuera de esos límites produce un error. En Java, cada fila puede tener longitud distinta; en Python también es posible que las listas internas tengan tamaños diferentes.
