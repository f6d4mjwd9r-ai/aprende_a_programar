RETO 01 / VARIABLES · FÁCIL

Calcula un promedio

Calcula el promedio de tres calificaciones y muestra el resultado.

Entrada: 8, 9, 10
Salida: 9.0

Pista: suma las notas y divide entre la cantidad de notas.

Mostrar solución en Java y Python

Python

notas = [8, 9, 10]
promedio = sum(notas) / len(notas)
print(promedio)

Java

public class Main {
    public static void main(String[] args) {
        double[] notas = {8, 9, 10};
        double suma = 0;
        for (double nota : notas) suma += nota;
        System.out.println(suma / notas.length);
    }
}
RETO 02 / CONDICIONES · FÁCIL

Clasifica un número

Lee un número e indica si es positivo, negativo o igual a cero.

Entrada: -3
Salida: Negativo

Pista: compara primero con 0 usando > y <.

Mostrar solución en Java y Python

Python

numero = int(input())
if numero > 0:
    print("Positivo")
elif numero < 0:
    print("Negativo")
else:
    print("Cero")

Java

import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int numero = sc.nextInt();
        if (numero > 0) System.out.println("Positivo");
        else if (numero < 0) System.out.println("Negativo");
        else System.out.println("Cero");
        sc.close();
    }
}
RETO 03 / CICLOS · FÁCIL

Suma una secuencia

Usa un ciclo para sumar los números del 1 al 100 y mostrar el total.

Entrada: ninguna
Salida: 5050

Pista: inicia la suma en 0 y agrega cada número en cada vuelta.

Mostrar solución en Java y Python

Python

total = 0
for numero in range(1, 101):
    total += numero
print(total)

Java

public class Main {
    public static void main(String[] args) {
        int total = 0;
        for (int numero = 1; numero <= 100; numero++) {
            total += numero;
        }
        System.out.println(total);
    }
}
RETO 04 / FUNCIONES · MEDIO

Convierte temperaturas

Crea una función que convierta grados Celsius a Fahrenheit con la fórmula F = C × 9 / 5 + 32.

Entrada: 25 °C
Salida: 77.0 °F

Pista: recibe Celsius como parámetro y devuelve el cálculo.

Mostrar solución en Java y Python

Python

def a_fahrenheit(celsius):
    return celsius * 9 / 5 + 32

print(a_fahrenheit(25))

Java

public class Main {
    static double aFahrenheit(double celsius) {
        return celsius * 9 / 5 + 32;
    }

    public static void main(String[] args) {
        System.out.println(aFahrenheit(25));
    }
}
RETO 05 / COLECCIONES · MEDIO

Busca el valor mayor

Recorre varios números y encuentra el valor más grande.

Entrada: 4, 9, 2
Salida: 9

Pista: guarda el primero como máximo inicial y actualízalo cuando encuentres uno mayor.

Mostrar solución en Java y Python

Python

numeros = [4, 9, 2]
mayor = numeros[0]
for numero in numeros:
    if numero > mayor:
        mayor = numero
print(mayor)

Java

public class Main {
    public static void main(String[] args) {
        int[] numeros = {4, 9, 2};
        int mayor = numeros[0];
        for (int numero : numeros) {
            if (numero > mayor) mayor = numero;
        }
        System.out.println(mayor);
    }
}
RETO 06 / CADENAS · MEDIO

Cuenta las vocales

Cuenta cuántas vocales aparecen en una frase, sin distinguir mayúsculas de minúsculas.

Entrada: Hola Mundo
Salida: 4

Pista: convierte el texto a minúsculas y revisa cada carácter.

Mostrar solución en Java y Python

Python

frase = "Hola Mundo".lower()
vocales = "aeiou"
cantidad = sum(1 for letra in frase if letra in vocales)
print(cantidad)

Java

public class Main {
    public static void main(String[] args) {
        String frase = "Hola Mundo".toLowerCase();
        int cantidad = 0;
        for (int i = 0; i < frase.length(); i++) {
            if ("aeiou".indexOf(frase.charAt(i)) >= 0) cantidad++;
        }
        System.out.println(cantidad);
    }
}
