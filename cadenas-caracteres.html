Cadenas y extracción de caracteres

Una cadena de texto (o string) es una secuencia de caracteres, como una palabra o una frase. Puedes consultar un carácter individual o extraer una parte de la cadena mediante sus posiciones, llamadas índices.

Las posiciones comienzan en cero

En Java y Python, el primer carácter está en el índice 0, el segundo en 1, y así sucesivamente. En el texto "Hola", el carácter 'H' está en la posición 0 y la 'l' está en la posición 2.

Obtener un carácter o un fragmento

Java usa charAt(indice) para obtener un carácter. Python permite acceder con corchetes. Para extraer varios caracteres, Python usa cortes: el índice final no se incluye.

Java

String palabra = "programar";
char primero = palabra.charAt(0);
String fragmento = palabra.substring(0, 4);

System.out.println(primero);    // p
System.out.println(fragmento); // prog

Python

palabra = "programar"
primero = palabra[0]
fragmento = palabra[0:4]

print(primero)    # p
print(fragmento)  # prog

¿Cómo se obtiene el carácter y el fragmento?

  1. palabra guarda el texto "programar". Sus posiciones empiezan en cero: p está en 0, r en 1, o en 2 y g en 3.
  2. palabra.charAt(0) en Java y palabra[0] en Python piden el carácter de la posición 0: la letra p.
  3. substring(0, 4) en Java y [0:4] en Python extraen desde la posición 0 hasta antes de la 4. Por eso el fragmento contiene p, r, o, g: "prog".
  4. Las instrucciones de salida muestran primero la letra y luego el fragmento, cada uno en una línea.

Revisar la longitud y recorrer el texto

La longitud indica cuántos caracteres tiene la cadena. Java la obtiene con length() y Python con len(). Puedes combinar la longitud con un ciclo para visitar cada posición.

Java

String texto = "sol";
for (int i = 0; i < texto.length(); i++) {
    System.out.println(texto.charAt(i));
}

Python

texto = "sol"
for caracter in texto:
    print(caracter)

Recuerda que intentar acceder a un índice que no existe produce un error. Asegúrate de que la posición esté entre cero y la longitud de la cadena menos uno.
