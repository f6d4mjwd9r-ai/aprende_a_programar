Fundamentos · Reutilizar instrucciones

Funciones

Una función agrupa instrucciones que realizan una tarea. Puedes darle un nombre y ejecutarla cada vez que la necesites, en lugar de copiar el mismo código en varios lugares.

Parámetros y resultados

Los parámetros son los datos que recibe una función. Si la función calcula algo, puede devolver el resultado con return. Así, otras partes del programa pueden utilizarlo.

  • Define la tarea con un nombre claro.
  • Recibe como parámetros solo los datos que necesita.
  • Devuelve un resultado si la tarea produce uno.

Calcular el área de un rectángulo

La función recibe el ancho y el alto, los multiplica y devuelve el área. En Java, las funciones que pertenecen a una clase se llaman métodos.

Java

public class Main {
    static double area(double ancho, double alto) {
        return ancho * alto;
    }

    public static void main(String[] args) {
        System.out.println(area(4, 3));
    }
}

Python

def area(ancho, alto):
    return ancho * alto

resultado = area(4, 3)
print(resultado)

Cuándo conviene crear una función

Conviene cuando un bloque de instrucciones se repite, cuando una tarea se puede describir con un nombre, o cuando dividir un problema hace que el programa sea más fácil de leer y probar.
