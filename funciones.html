Fundamentos · Reutilizar instrucciones

Funciones

Una función agrupa instrucciones que realizan una tarea. Puedes darle un nombre y ejecutarla cada vez que la necesites, en lugar de copiar el mismo código en varios lugares.

Parámetros y resultados

Los parámetros son los datos que recibe una función. Al llamarla, los valores concretos que le pasas se llaman argumentos. Si la función calcula algo, puede devolver el resultado con return; así, otras partes del programa pueden guardarlo, mostrarlo o usarlo en otro cálculo.

  • Define la tarea con un nombre claro.
  • Recibe como parámetros solo los datos que necesita; los argumentos se asignan a esos parámetros al hacer la llamada.
  • Devuelve un resultado con return si la tarea produce uno.

Calcular el área de un rectángulo

La función recibe el ancho y el alto, los multiplica y devuelve el área. En Java, las funciones que pertenecen a una clase se llaman métodos.

Java

public class Main {
    static double area(double ancho, double alto) {
        return ancho * alto;
    }

    public static void main(String[] args) {
        System.out.println(area(4.0, 3.0));
    }
}

Python

def area(ancho, alto):
    return ancho * alto

resultado = area(4.0, 3.0)
print(resultado)

¿Qué hace el programa paso a paso?

  1. La definición empieza con def area(ancho, alto) en Python o con static double area(double ancho, double alto) en Java. Definirla prepara las instrucciones, pero no calcula el área todavía.
  2. El programa llama a la función con area(4.0, 3.0). Esa llamada inicia la tarea y pasa dos argumentos: 4.0 y 3.0.
  3. Al comenzar la ejecución, esos argumentos se asignan a los parámetros ancho y alto. La función calcula ancho * alto.
  4. return devuelve el resultado 12.0 al lugar donde se hizo la llamada y termina esa ejecución de la función.
  5. Python guarda el valor devuelto en resultado y después lo imprime. Java pasa el valor devuelto directamente a System.out.println.

Lo que verás en la consola:12.0

Devolver un valor no es lo mismo que mostrarlo

return entrega un valor para que el programa lo pueda seguir usando. print en Python y System.out.println en Java solo muestran información en la consola. Por ejemplo, una función que devuelve un área permite guardarla en una variable o compararla; mostrarla es una acción separada.

No todas las funciones tienen que devolver un resultado: algunas realizan una acción, como mostrar un mensaje. En Java, un método que no devuelve un valor se declara con void; en Python, se puede escribir una función sin return explícito.

Cuándo conviene crear una función

Conviene cuando un bloque de instrucciones se repite, cuando una tarea se puede describir con un nombre, o cuando dividir un problema hace que el programa sea más fácil de leer y probar.
