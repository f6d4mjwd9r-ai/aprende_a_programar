Clases y objetos

Una clase es una descripción que reúne datos y acciones relacionados. Un objeto es un ejemplar concreto creado a partir de esa descripción, con sus propios valores.

Una clase para representar libros

La clase Libro puede definir el título y el autor como datos, y una acción para mostrar una descripción. Cada libro creado será un objeto que tendrá sus propios datos.

Java

class Libro {
    String titulo;
    String autor;

    Libro(String titulo, String autor) {
        this.titulo = titulo;
        this.autor = autor;
    }

    void mostrar() {
        System.out.println(titulo + " — " + autor);
    }
}

Libro libro = new Libro("El principito", "Antoine");
libro.mostrar();

Python

class Libro:
    def __init__(self, titulo, autor):
        self.titulo = titulo
        self.autor = autor

    def mostrar(self):
        print(f"{self.titulo} — {self.autor}")

libro = Libro("El principito", "Antoine")
libro.mostrar()

Datos y métodos

Los datos de un objeto se suelen llamar atributos. Las funciones definidas dentro de la clase son métodos: describen acciones que ese objeto puede realizar. En Java se accede al objeto creado mediante una referencia; en Python, self representa el objeto actual dentro de sus métodos.
