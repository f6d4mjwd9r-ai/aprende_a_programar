Java y Python paso a paso

Una lógica, dos lenguajes

Empieza por la idea, sigue los datos y compara cómo se escribe la misma solución en cada lenguaje. En el primer ejemplo Java, Main y main son la plantilla; por ahora, cambia solo las instrucciones dentro de main.

En los ejemplos que piden un dato, escríbelo en la consola cuando el programa lo solicite.

1. Saber si un número es par

  1. EntradaLee un número entero, como 8.
  2. Proceso% obtiene el residuo: 8 % 2 es 0.
  3. DecisiónCompara el residuo con 0; así obtienes verdadero o falso.
  4. SalidaMuestra si el número es par.

Python

numero = int(input("Escribe un número: "))
es_par = numero % 2 == 0
print(es_par)

Java

import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Escribe un número: ");
        int numero = sc.nextInt();
        boolean esPar = numero % 2 == 0;
        System.out.println(esPar);
        sc.close();
    }
}

Entrada: 8 · Salida: true en Java y True en Python.

2. Calcular un promedio

  1. EntradaRecibe dos notas decimales.
  2. ProcesoSúmalas y divide entre 2.
  3. ComprobaciónCon 8 y 10: (8 + 10) / 2 = 9.

Python

nota1 = float(input("Primera nota: "))
nota2 = float(input("Segunda nota: "))
promedio = (nota1 + nota2) / 2
print(promedio)

Java

import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        double nota1 = sc.nextDouble();
        double nota2 = sc.nextDouble();
        double promedio = (nota1 + nota2) / 2;
        System.out.println(promedio);
        sc.close();
    }
}

Entrada: 8 y 10 · Salida: 9.0.

3. Sumar con un ciclo

  1. InicioEmpieza con total igual a 0.
  2. RepeticiónAgrega al total cada número del 1 al 5.
  3. SalidaEl total final es 15.

Python

total = 0
for numero in range(1, 6):
    total += numero
print(total)

Java

public class Main {
    public static void main(String[] args) {
        int total = 0;
        for (int numero = 1; numero <= 5; numero++) {
            total += numero;
        }
        System.out.println(total);
    }
}

Salida: 15.

4. Recorrer una lista

  1. DatosGuarda varios números juntos.
  2. RecorridoVisita cada elemento con un ciclo.
  3. ResultadoCalcula y muestra la suma: 4 + 9 + 2 = 15.

Python

numeros = [4, 9, 2]
total = 0
for numero in numeros:
    total += numero
print(total)

Java

import java.util.ArrayList;

public class Main {
    public static void main(String[] args) {
        ArrayList<Integer> numeros = new ArrayList<>();
        numeros.add(4);
        numeros.add(9);
        numeros.add(2);
        int total = 0;
        for (int numero : numeros) {
            total += numero;
        }
        System.out.println(total);
    }
}

Salida: 15.
