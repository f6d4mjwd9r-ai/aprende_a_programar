Java y Python paso a paso

Una lógica, dos lenguajes

Vamos a comprobar si un número es par. La lógica es igual en ambos lenguajes: calcular el residuo de dividir entre dos y verificar si es cero.

  1. EntradaEl programa recibe un número entero, por ejemplo, 8.
  2. ProcesoEl operador % obtiene el residuo de la división: 8 % 2 es 0.
  3. DecisiónLa comparación residuo == 0 produce un valor verdadero o falso.
  4. SalidaEl programa muestra true/True si es par y false/False si es impar.

Java: guarda el código como Main.java

public class Main {
    public static void main(String[] args) {
        int numero = 8;
        boolean esPar = numero % 2 == 0;
        System.out.println(esPar);
    }
}

Python: guarda el código como programa.py

numero = 8
es_par = numero % 2 == 0
print(es_par)

Ejecuta Java con javac Main.java y luego java Main. Para Python usa python programa.py o, en Windows, py programa.py.
