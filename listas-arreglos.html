Fundamentos · Agrupar valores

Listas y arreglos

Las colecciones permiten guardar varios valores relacionados bajo una sola variable. Así puedes recorrerlos con un ciclo, consultar un elemento y, según la colección, agregar o quitar valores.

Posiciones e índices

Los elementos se guardan en posiciones. En Java y Python, el primer índice es 0, no 1. Por eso, en una colección de tres elementos, las posiciones son 0, 1 y 2.

Recorrer una colección

Este ejemplo guarda tres calificaciones y calcula su promedio. Python usa listas; en Java el arreglo tiene un tamaño fijo y ArrayList permite agregar elementos.

Java

int[] notas = {8, 9, 10};
int suma = 0;

for (int nota : notas) {
    suma += nota;
}

double promedio = (double) suma / notas.length;
System.out.println(promedio);

Python

notas = [8, 9, 10]
suma = 0

for nota in notas:
    suma += nota

promedio = suma / len(notas)
print(promedio)

Elige la colección adecuada

Un arreglo sirve cuando conoces el tamaño y no necesitas cambiarlo. Una lista como la de Python o un ArrayList de Java es útil cuando necesitas una colección que pueda crecer o reducirse.
